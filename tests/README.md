# tests

Testes unitários dos módulos em `assets/js/`, rodados com o test runner nativo do Node (`node --test`) — zero dependência externa, mantendo a mesma filosofia de "sem build" do site publicado. O `package.json` na raiz existe só como ferramenta de dev (nunca é servido pelo GitHub Pages).

Rodar: `npm test` (a partir da raiz do repositório).
